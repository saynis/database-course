REVIEW CHALLENGE 1 (Lessons 1–12)

No new concepts are introduced here — only what you've already learned.

Scenario: A small bookstore wants a database.

Task:

Create a database called bookstore.
Create a table books with appropriate columns and constraints: id (PRIMARY KEY), title (NOT NULL), author (NOT NULL), price (NUMERIC, CHECK > 0), in_stock (BOOLEAN, DEFAULT true).
Insert at least 6 books.
Write a query to find all books under $15, sorted by price ascending.
Write a query to find all books whose title contains the word "Guide" (any case).
Update the price of one book.
Delete one book that is out of stock (in_stock = false) — preview with SELECT first.

Restrictions: No JOIN, no GROUP BY, no subqueries, no foreign keys — none of that has been taught yet.
